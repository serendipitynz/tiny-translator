# Third-party notices

This file covers material by other authors that ships inside a tiny-translator bundle but is not
resolved from either lockfile, so no inventory built from `pnpm-lock.yaml` or `src-tauri/Cargo.lock`
would find it. `scripts/generate-third-party-licenses.mjs` reproduces this file in full as the first
section of `THIRD-PARTY-LICENSES.txt`, which every bundle carries.

The PLaMo 3 Translate model is not part of any bundle. The app downloads it from Preferred
Networks' Hugging Face repository after the user agrees to the PLaMo Community License, which the
app shows from `src/licenses/` (doc-1 §10.4).

Every licence text below is copied out of the source named beside it, not retyped.

## llama.cpp (the translation engine, `llama-server`)

The bundle carries `llama-server`, built from llama.cpp tag `b12110`
(commit `cd959bae99ff4bed22bef2604f45241c09bbb8c8`) by `scripts/build-llama-server.sh` (macOS,
Metal) or `scripts/build-llama-server.ps1` (Windows, Vulkan) into a single static executable. It
contains llama.cpp and ggml, and the libraries from llama.cpp's `vendor/` directory that
`llama-server` links. It is built without llama.cpp's Web UI, so none of the Web UI's packages are
in it.

Source: <https://github.com/ggml-org/llama.cpp>
