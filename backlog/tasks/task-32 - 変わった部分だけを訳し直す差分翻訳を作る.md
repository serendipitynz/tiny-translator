## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
リソースファイルやドキュメントは原文が少しずつ更新される。毎回全体を訳し直すと、手で直した訳が消え、変わっていない文の訳語もぶれる。前回の原文・前回の訳文・新しい原文から、増えた部分と変わった部分だけを訳し、それ以外は前回の訳文を残す (2026-11-10 オーナー判断、doc-2 §2 の差別化)。i18n のリソースファイルではキー単位、Markdown では段落などの翻訳単位で比べる形が考えられる。ファイルを入出力にする用途なので、入口は CLI (TASK-34) が自然だが、画面から使うかどうかは着手時に決める。
