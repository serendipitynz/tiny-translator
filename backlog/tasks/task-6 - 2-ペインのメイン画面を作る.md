## Implementation Notes

## 実装の要点

- 部品は `src/lib/ui/` に置いた: `Button` (主操作・通常)、`IconButton` (アイコンのみボタン)、`Select` (選択欄)、`Panel` (パネル)、`TextArea` (複数行入力)。画面は `App.svelte` が組み、各操作は空の関数 (`translate`・`swap`・`paste` など) を呼ぶだけにした。後続のタスク (TASK-9・10・11・20・21) はこの関数の中身を書けばよい。
- 無効は `aria-disabled` で表し、フォーカスを残す (doc-8 §5.4)。部品は `disabledReason` に語が渡されたときだけ無効になるので、理由の語を持たない無効は作れない。理由は `aria-describedby` と `title` で持ち、押されたら live region で読み上げる。理由を決める関数は `src/lib/blockers.ts` に分けた (原文が空なら翻訳・原文のコピー・クリアが無効、訳文が空なら訳文のコピーが無効)。
- 翻訳ボタンの処理中は、静止時の語「翻訳」と処理中の語「翻訳中…」(スピナー付き) を同じ格子のセルに重ね、見えない側も場所を保つ。幅は両方の長い方に固定される (doc-1 §8.2・doc-8 §6.1)。スピナーは snz-design の Storybook と同じく CSS の弧で描いた。
- 選択欄は、輪郭・面・山形の図形を外側の枠が描き、その内側に `appearance: none` で透明にした `select` を置いた (doc-1 §8.2・doc-8 §6.3)。`select` 自体は標準のままなので、一覧・キーボード操作・読み上げは OS のもの。フォーカス枠は `:has(select:focus-visible)` で枠の外側に出す。名前は `aria-labelledby` で名札の語だけにした (label で包むだけだと現在の値も名前に混ざる)。山形の図形 `chevron-down` は lucide-react v1.17.0 の `__iconNode` をそのまま写した。
- 入れ替えボタンは、doc-1 §8.1 の略図の下段ではなく、翻訳元の選択欄の行の右端 (2 つのパネルの境目) に置いた。選択欄の行をパネルと同じ 2 列にしたので、各選択欄は自分のパネルの真上に並び、入れ替えは 2 つの間に来る。図形は TASK-5 の左右の矢印のまま。
- 原文と訳文の複数行入力はパネルの本体を埋め、パネルの輪郭を入力欄の輪郭として使う。フォーカス枠はパネルの外側に出す。**doc-8 §6.3 の「複数行入力は高さを利用者が変えられる」とは違えている**: 2 つのペインがウィンドウを埋めるので、利用者が変えるのはウィンドウの大きさであり、ペインの中のつまみはウィンドウを超えて伸ばすことしかできないため。訳文は読み取り専用なので hover の面を出さない。
- 狭い幅の判定はウィンドウ幅ではなく `main` のコンテナ幅 (40rem 未満) で行う。将来履歴の一覧などが横に並んでも規則が崩れないため。
- 言語の選択肢 (自動判定 / 自動 (優先順位) と、日本語・英語・中国語 (簡体字・繁体字)・韓国語) は doc-1 §6.1 で判定を測った言語を仮に置いた。並べる言語とプロンプトへ渡す値は TASK-10 で決める。
- 形式の選択欄と「判定: 英語」の表示 (§8.1 の原文パネルの下段)、コピーの通知 (§8.2) は、それぞれを作る TASK-17・TASK-10・TASK-11 に残した。選択欄の無効と、アイコンのみボタン・パネルの処理中は、この画面に使う箇所が無いので作っていない。

## レビュー対応 (PR#6 の 1 回目、P2)

- 最小のウィンドウ (480×360) で上下に並べると、パネルの本体が約 30px しかないのに入力欄が最低 76.8px を求め、はみ出た行とカーソルが切れていた。入力欄は本体の高さちょうどにして内側でスクロールさせ、上下に並べたときは各パネルに 8rem の最低の高さを持たせた。ウィンドウがそれより低いときは `main` がスクロールし、パネルが翻訳ボタンに重ならない。
- 直す途中で、選択欄の行に当てていた `min-block-size: 0` のせいで、高さが足りないとその行が 0 に潰れることが分かったので外した。
- 480×360・960×360・960×640・480×640 で、入力欄が本体からはみ出ないこと、12 行入れて最終行までスクロールで見えること、パネルの下端が翻訳ボタンの上端より上にあること、ページ全体ではなく `main` だけがスクロールすることを測った。
