## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
翻訳履歴 (m-4、doc-1 §9) は今は見返すためだけにある。以前に訳した文と同じ文が来たら、モデルを通さずに以前の訳文を使えば、速く、訳語もそろう (2026-11-10 オーナー判断、doc-2 §2 の差別化)。履歴を持つ先行事例はあるが、翻訳に使うものは無い。今の履歴は 1 回の翻訳の原文と訳文を丸ごと保存し、上限は 1,000 件なので、翻訳単位ごとに引くには保存の形か別の索引が要る。似た文の以前の訳を参考に出すかどうかは着手時に決める。
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 以前に訳した翻訳単位と原文・翻訳先言語・形式が同じ翻訳単位は、モデルを通さずに以前の訳文を使う
- [ ] #2 以前の訳文を使った翻訳単位が画面で分かり、その単位だけモデルで訳し直せる
- [ ] #3 翻訳メモリを使うかどうかを設定で切り替えられる
- [ ] #4 履歴を削除すると、その翻訳から得た翻訳メモリも使われなくなる
- [ ] #5 照合の単位・保存の形・件数の上限を決め、doc-1 §9 に書いている
<!-- AC:END -->
